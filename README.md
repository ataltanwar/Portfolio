## 🚀 Getting Started

### 1️ Clone the repository

```bash
git clone https://github.com/ataltanwar/portfolio.git
```

### 2️ Install dependencies

```bash
npm install
```

### 3️ Run the project

```bash
npm run dev
```

The website will run on:

```
http://localhost:3000
```
